# Deep Init

Generates or refreshes hierarchical `AGENTS.md` documentation across a codebase -- one file per directory, linked by parent-reference tags, describing purpose, key files, and conventions for AI agents working in that area.

## When to Use

- Bootstrapping AI-readable docs for a new or undocumented codebase
- Refreshing existing `AGENTS.md` files after structural changes
- Establishing per-directory conventions and testing requirements for agents
