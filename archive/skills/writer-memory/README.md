# Writer Memory

Agentic memory system for fiction writers. Tracks characters, relationships, scenes, and themes across sessions in `.writer-memory/memory.json`, so voice, arcs, and continuity survive between chapters and sessions.

Includes dialogue validation against a character's established tone/taboo words, natural-language queries against the story's memory, and emotion-focused synopsis generation.

## When to Use

- Writing fiction and need to remember characters, relationships, or worldbuilding across sessions
- Checking whether a line of dialogue matches a character's established voice
- Generating a synopsis or checking thematic coherence
- Tracking how a relationship or character arc evolves scene to scene
