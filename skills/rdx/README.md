# RDX

Terse, precise, and maximum-efficiency developer mode. Minimizes prose token cost and avoids speculative, over-engineered code solutions.

## What It Does

| Dimension | Description |
| --- | --- |
| Prose | Drops articles, filler, pleasantries, and hedging. Prefers direct fragments. |
| Code | Applies the YAGNI ladder: stdlib/native/dependencies before custom code. |
| Verification | Demands evidence (checks, callers, contracts) before asserting correctness. |

---

## When to Use

Triggers when you:
- Request RDX mode, /rdx, or extreme brevity.
- Need a YAGNI-first implementation strategy.
- Seek minimal, focused diffs without unnecessary abstractions.
