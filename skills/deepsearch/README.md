# Deep Search

Thorough codebase search when a single grep isn't enough: broad matching, deep-dive into imports/exports, and a synthesized map of primary implementations vs. related/consumer files.

## When to Use

- Locating where a concept, symbol, or pattern is implemented and used
- Mapping the usage/consumer graph for a piece of code
- A quick grep returns too many or too few leads to be conclusive
