# Prompt Engineer

Pointer to Anthropic's current Claude prompting guides and the `claude-api` skill, plus the ten rules that most often go wrong in prompts for current models.

## What It Does

| Area | Covers |
| --- | --- |
| Sources | General prompting guide, Opus 5.5 guide, `claude-api` for parameters |
| Rules | Normal volume, reasons over bare commands, examples over don'ts, no forced reasoning output, no ceremonial verification, targeted triggers, early-stop pattern, short output specs |

---

## When to Use

Triggers when you:

- Write or review a system prompt, agent prompt, or skill
- Design few-shot examples or output-format specs
