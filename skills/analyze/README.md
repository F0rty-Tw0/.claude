# Analyze

Deep investigation of architecture, bugs, performance issues, and dependencies. Routes to the `architect` agent or the `ask_codex` agentic-mcp tool for cross-file reasoning, then returns structured findings with file:line evidence and actionable recommendations.

## When to Use

- Root-causing a bug or performance issue
- Understanding a system's architecture or behavior before changing it
- Assessing the impact/dependencies of a proposed change
- A question spans multiple files and needs cross-file reasoning
