# Skill

CLI-style meta-skill for managing local skills: list, add, remove, edit, search, sync, and scaffold skills across user and project scope.

## When to Use

- Listing, searching, or inspecting installed skills
- Creating a new skill from a template (error / workflow / pattern / integration)
- Editing, renaming, or removing an existing skill
- Syncing skills between user (`~/.claude/skills/learned/`) and project (`.claude/local/skills/`) scope
