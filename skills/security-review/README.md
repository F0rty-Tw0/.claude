# security-review

Conducts a thorough security audit checking for OWASP Top 10 vulnerabilities, hardcoded secrets, and unsafe patterns, delegating to the `security-reviewer` agent.

## When to Use

- User requests "security review" or "security audit"
- After writing code that handles user input
- After adding new API endpoints
- After modifying authentication/authorization logic
- Before deploying to production
- After adding external dependencies
