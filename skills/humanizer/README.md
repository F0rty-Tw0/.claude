# Humanizer

Identify and remove signs of AI-generated text, making writing sound natural and human. Based on Wikipedia's "Signs of AI writing" maintained by WikiProject AI Cleanup.

## What It Does

Scans for and rewrites five categories of AI patterns:

| Category             | Examples                                                              |
| -------------------- | --------------------------------------------------------------------- |
| **Content**          | Significance inflation, promotional language, vague attributions      |
| **Language/Grammar** | Overused AI vocabulary (delve, pivotal, tapestry), copula avoidance   |
| **Style**            | Em dash overuse, excessive boldface, inline-header lists, emojis      |
| **Communication**    | "I hope this helps", sycophantic tone, "Let's explore" openers       |
| **Filler/Hedging**   | Filler phrases, generic conclusions, transition summaries             |

Also emphasizes adding personality: opinions, varied rhythm, first-person perspective, and specificity about feelings.

---

## When to Use

Triggers when you:

- Edit AI-drafted content before publishing
- Review text that sounds "off" or generic
- Polish docs, articles, or messages that feel robotic

---

## When NOT to Use

- Technical documentation where precision matters more than voice
- Code comments, API docs, changelogs
- Legal or compliance text with required phrasing
