# Chrome Extensions

Build production-quality Chrome extensions on Manifest V3 and publish them to the Chrome Web Store. The skill front-loads the 18 gotchas that most often produce a broken build, then defers full API patterns to per-topic files in `references/extensions/` and publishing guidance to `references/webstore/`.

Part 1 covers building (mandatory rules, MV3 requirements, an output checklist); Part 2 covers publishing (managing `CHROMEWEBSTORE.md`, permission justifications, privacy policy, pre-publish checklist).

## When to Use

- Creating, modifying, or debugging a Chrome/browser extension or anything using the `chrome.*` APIs
- Working with `manifest.json`, content scripts, service workers, side panels, popups, omnibox, or context menus
- Publishing to the Chrome Web Store: writing permission justifications, drafting a privacy policy, or responding to a review rejection
