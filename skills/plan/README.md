# plan

Strategic planning skill with an optional interview workflow. Auto-detects whether to interview the user for a vague/broad request or generate a plan directly for a detailed one, and supports a multi-perspective consensus mode (Planner -> Architect -> Critic loop) and a review mode for evaluating an existing plan.

## When to Use

- Planning before implementing ("plan this", "let's plan")
- Structured requirements gathering for a vague idea
- Reviewing an existing plan (`--review`)
- Multi-perspective consensus on a plan (`--consensus`, "ralplan")
- Scoping a broad or vague task before any code is written
