# Note

Saves context to `.claude/local/notepad.md` so it survives conversation compaction. Supports Working Memory (timestamped, auto-pruned), Priority Context (short, load-bearing facts), and MANUAL (permanent) sections.

## When to Use

- Recording a debugging breadcrumb or temporary finding mid-session
- Saving a critical fact you want to read back later (`note --priority`)
- Recording permanent reference info like team contacts or deployment details
