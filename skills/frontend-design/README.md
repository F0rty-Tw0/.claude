# Frontend Design

Create distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Real working code with exceptional attention to aesthetic details and creative choices.

## What It Does

Guides design thinking and implementation across five aesthetic dimensions:

| Dimension        | Focus                                                                  |
| ---------------- | ---------------------------------------------------------------------- |
| **Typography**   | Distinctive, characterful fonts - never Arial, Inter, Roboto           |
| **Color**        | Dominant colors with sharp accents, CSS variables for consistency      |
| **Motion**       | CSS animations, scroll-triggering, staggered reveals, hover states     |
| **Composition**  | Asymmetry, overlap, diagonal flow, grid-breaking, negative space       |
| **Backgrounds**  | Gradient meshes, noise textures, geometric patterns, grain overlays    |

Supports bold aesthetic directions: brutalist, art deco, organic, luxury, retro-futuristic, editorial, and more.

---

## When to Use

Triggers when you:

- Build web components, pages, or applications needing production-grade design
- Want to avoid cookie-cutter, generic AI aesthetics
- Need distinctive visual identity with intentional creative choices

---

## Core Principle

Choose a clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism both work - the key is intentionality, not intensity. No two designs should look the same.
