# Wrap-Up

End-of-session checklist for cleanup, memory, and self-improvement. Runs three phases to close out a work session cleanly.

## What It Does

Guides a structured session close-out:

1. **Clean Up** - Verify file placement, fix naming violations, resolve stale tasks
2. **Remember It** - Route session learnings to the right memory layer (auto memory, CLAUDE.md, rules, local)
3. **Review & Apply** - Identify skill gaps, friction, and automation opportunities; apply approved improvements

---

## When to Use

Triggers when you:

- Say "wrap up", "close session", "end session", or "wrap things up"
- Invoke `/wrap-up` directly
- Finish a task and want a clean close-out

---

## Key Principles

- Confirm before moving or renaming files — never auto-apply destructive changes
- Route knowledge to the lightest-weight memory layer that fits
- Skip phases that have nothing to report — no ceremony for its own sake
- Present findings for approval before applying self-improvement changes
