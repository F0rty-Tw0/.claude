# Research

Orchestrates parallel `scientist` agents to investigate a research goal: decompose it into independent stages, run them concurrently with model tiers matched to complexity, cross-validate the findings, and synthesize a cited report. Supports an autonomous AUTO mode that loops until a completion promise is emitted.

## When to Use

- A research goal or question can be split into independent investigation stages
- Comprehensive, cross-validated, multi-angle analysis of a codebase or topic is needed
- Fully autonomous multi-stage investigation is wanted, ending in a synthesized report
